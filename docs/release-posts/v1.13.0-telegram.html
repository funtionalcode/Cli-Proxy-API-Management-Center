🚀 9 月 17 日 · v1.13.0 🤖 Devin Provider 支持 • CPAMP 现在可以识别 Devin 凭证和 devin/* 模型，并在 Accounts、OAuth、Request Monitoring 等现有页面中正常展示。 • 新增 Devin OAuth 授权流程，支持远程回调 URL、授权状态轮询、取消和重新授权。 • 新增 Devin Daily / Weekly 额度窗口、重置时间和订阅计划信息，并接入现有账号额度快照与历史窗口展示。 • Visual Config 新增 devin.sensitive-words 编辑支持，保存时会保留其他未知 Devin 配置。 🛠 可靠性与升级修复 • 修复浏览器版本或 User-Agent 变化后，已记住的 CPAMP Admin Key 可能无法恢复的问题；旧格式只会在成功认证后迁移。 • 修复旧版 Native 安装使用 <install_dir>/data 时升级可能找不到历史数据的问题，并重新支持 bash install-cpamp.sh update。 • 模型价格缺失提醒改为固定尺寸图标，并限制只在对应主费用卡片显示，减少布局抖动和重复提示。 ⚠️ 升级说明 • 本版本无数据库 schema 迁移，不需要离线维护，也没有新增 CPAMP 必填配置项。 • 使用 Devin 时建议先将 CPA 升级到 v7.3.2 或更高版本，以获得完整的 OAuth 回调支持。 • Devin 的请求执行、OAuth 认证和上游协议仍由 CPA 负责，CPAMP 不实现独立的 Devin 请求传输层。 GitHub Release
