## Overview

v1.13.2 is a maintenance release focused on provider compatibility and quota/accounting correctness. The main addition is end-to-end Muse / Meta integration in CPA Manager Plus, covering OAuth Device Flow, credential identity, quota windows and historical snapshots, Meta API-key provider management, model discovery, health checks, and monitoring source resolution.

This release also closes three correctness gaps. Codex Reset Credit count evidence and detail evidence are now tracked independently so count-only refreshes or stale snapshots cannot incorrectly refresh details. xAI Weekly windows remain visible when valid period metadata exists without a numeric usage percentage, while zero monthly limits no longer synthesize nonexistent Monthly windows. Devin usage now uses the correct cache-input accounting semantics and automatically reconciles affected historical derived data.

## Highlights

### Muse / Meta

- Add Muse / Meta provider identity with canonical ID `meta` and compatibility alias `muse`. (Web / Manager Server)
- Integrate CPA Meta OAuth Device Flow so CPAMP can request the authorization URL and device code and poll login status. (Web / CPA)
- Show Muse quota and reset windows in Accounts and persist them through the existing quota snapshot/history pipeline. Valid windows without a usable percentage remain successful unknown observations instead of being reported as 0%. (Web / Manager Server)
- Add `meta-api-key` provider management, including create/edit/delete, enable/disable, priority/weight, model mappings, model discovery, connectivity, and health checks. (Web / CPA)
- Recognize Meta sources and runtime identities in Request Monitoring and Usage Analytics. (Web)
- Keep OAuth DCA credentials strictly separate from Meta inference API keys. DCA values are rejected from inference-provider save, discovery, connectivity, and health-check paths. (Web / CPA)

### Codex Reset Credits

- Track Reset Credit available-count evidence and detail-list evidence independently so a count-only refresh cannot extend stale detail validity. (Web / Manager Server)
- Preserve a local invalidation boundary after Reset Credit consumption so older quota snapshots cannot restore consumed counts or details. (Web / Manager Server)
- Preserve an explicit empty detail list as authoritative zero-credit evidence, while missing or malformed detail payloads cannot clear trusted existing details. (Web / Manager Server)
- Trigger a single on-demand detail refresh when the Quota tab opens and Reset Credit details are missing, stale, or older than five minutes. (Web)
- Show expiration remaining time in days, hours, minutes, or less than one minute, and remove expired credits once the boundary is reached. (Web)

### xAI Quota

- Preserve the Weekly quota card when xAI returns valid Weekly period boundaries without `usagePercent`, showing unknown progress and the correct reset metadata. (Web / Manager Server)
- Stop treating `monthlyLimit = 0` as evidence for a Monthly financial quota window across Accounts, Monitoring, and Manager Server inspection. (Web / Manager Server)

### Devin Usage Accounting

- Add the `read_included_creation_separate` cache-input accounting mode: cache reads are deducted from prompt input while cache creation is counted separately in total input, preventing Devin usage from being over- or under-counted. (Web / Manager Server)
- Apply this mode with priority to Devin executors, providers, and model prefixes while preserving an explicit positive upstream `total_tokens` value as authoritative. (Web / Manager Server)
- Automatically advance `usage_cache_accounting_semantics_revision` to revision 2 and re-derive only affected historical Devin rollups. (Manager Server)

### Docs

- Document Muse / Meta OAuth, AI Provider, Accounts, and capability behavior, including the CPA `v7.3.4+` full-support baseline and the DCA / `meta-api-key` credential boundary.

## Upgrade Notes

- **Complete Muse / Meta support requires CPA v7.3.4 or later.** CPA v7.3.4 introduced the native Meta (Muse Code) provider, Meta OAuth management endpoint, and `meta-api-key` management support.
- **No manual database migration or offline maintenance is required.** On startup, Manager Server checks the Devin cache-accounting semantics revision. Instances without historical Devin usage complete revision 2 immediately; affected instances automatically recalculate the relevant usage and derived rollups.
- Muse / Meta quota snapshots, Codex Reset Credit evidence separation, and the xAI Weekly fixes add no new database tables or columns.
- Downgrading from v1.13.2 does not require a database rollback, but older versions cannot preserve the new explicit-empty Reset Credit detail semantics and may temporarily fall back to older snapshot details until fresh quota evidence is collected.
