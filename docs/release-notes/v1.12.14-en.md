# CPA Manager Plus v1.12.14

> 35 commits since v1.12.13

> [中文 ->](https://github.com/seakee/CPA-Manager-Plus/blob/v1.12.14/docs/release-notes/v1.12.14-zh.md)

## Overview

v1.12.14 is a small maintenance release focused on model-price management and monitoring readability. Manager Server can now discover models currently exposed by CPA before they have produced any usage, allowing price synchronization to cover them ahead of first use. The Web UI surfaces newly discovered models that are still missing prices across Dashboard, Request Monitoring, and Usage Analytics, with a direct path into the missing-price filter.

The manual Model Prices editor now preserves and edits context-threshold and service-tier pricing rules, including inherited fields and explicit zero prices, instead of dropping synchronized advanced rules when base prices are changed. This release also fixes opaque-hash and unknown-provider source presentation in monitoring, improves narrow-screen auto-refresh controls, and adds `-v` / `--version` reporting to Manager Server.

This release introduces no database schema migration, requires no offline maintenance, and adds no required configuration.

## Highlights

### Features

- Add Manager Server `-v` / `--version`. Version queries print the binary version and exit before configuration, database, or network initialization. (Manager Server)
- Add missing model-price attention across Dashboard, Request Monitoring, and Usage Analytics. Newly discovered runtime models without prices are surfaced consistently and link directly to the Model Prices `missing` filter. (Web / Manager Server)
- Extend the Model Prices manual editor with context-threshold and service-tier rule editing. Rules can be added, updated, and removed while preserving inheritance and explicit `$0` semantics. (Web)

### Fixes

- Include models currently exposed by CPA in price synchronization before their first UsageEvent. If runtime discovery fails, synchronization falls back to known models without clearing existing prices or incorrectly acknowledging pending models that were never checked. (Manager Server / Web)
- Fix overlapping auto-refresh controls in Request Monitoring at narrow widths such as 320px and 360px. (Web)
- Fix opaque `h:<sha256>` source identities taking precedence over readable metadata; account, channel, host, and other readable source evidence are preferred when available. (Web)
- Fix unknown or dynamic provider labels taking precedence over credential account identity. Provider-like labels no longer hide a more useful account name while distinct custom channels and key disambiguation remain intact. (Web)
- Preserve synchronized context/service-tier rules when manually editing an existing model's base price, and continue refreshing missing-price attention after a successful save. (Web)

## Upgrade Notes

- **No database schema migration or offline maintenance is required.** Existing data structures and deployment modes remain compatible.
- No new required configuration or minimum CPA version is introduced.
- Runtime model discovery is performed by Manager Server through the existing CPA Management API and `/v1/models`; CPA API keys are not exposed to the browser or sent to external price catalogs.
- If runtime model discovery is unavailable, price synchronization safely falls back to the existing known-model path; existing manual prices remain authoritative.
- Advanced pricing-rule editing changes only existing Model Price data and does not modify routing, provider configuration, or credentials.
