## Overview

v1.12.12 主要完善凭证列表的响应式展示和额度可读性。表格与卡片模式现在能更完整地呈现额度窗口、历史用量、订阅与账户信息，同时收紧 xAI 未确认额度的展示规则。本版本为前端展示与选择逻辑更新，不包含数据库 schema、凭证存储或 usage 原始数据迁移。

## Highlights

### Features

- 重做凭证列表的响应式布局，在移动端、笔记本和桌面宽度下改善列表与卡片模式；提供更清晰的 Provider、套餐、订阅、重置额度、优先级、备注与额度信息，并保留现有账户操作。（Web）
- 表格模式最多展示四个额度窗口，并按窗口数量自适应布局；单窗口充分利用额度列，三窗口使用独立第三行，四窗口采用 2×2 排列，同时为「可用状态」与「最近请求」保留更稳定的可读空间。（Web）
- 卡片与表格恢复四项历史用量指标，并使用紧凑值展示与完整可访问值，减少信息缺失和窄屏溢出。（Web）
- Antigravity `Pro`、`Ultra` 与 `Ultra Lite` 卡片现在可直接展示完整四个 `5h` / `7d` 额度窗口，并按模型族分组；其他 Provider 与 Antigravity Free 继续保持更紧凑的窗口数量。（Web）
- 凭证列表支持更完整的优先级与备注展示，并保留内联编辑能力。（Web）

### Fixes

- xAI Free 与无法确认的未知套餐不再把 billing limit 误展示为可用额度；只有明确识别的付费套餐才会暴露对应 quota / PAYG 信息，诊断所需的原始 billing 数据仍会保留。（Web）
- 统一主列表额度窗口的选择、排序与历史用量目标，避免表格实际展示窗口和后台用量查询目标不一致。（Web）

## Upgrade Notes

- 本版本不包含数据库 schema 迁移，也不会修改 usage 历史数据或凭证存储。
- 无新增必填配置项，Manager Server、CPA-hosted / external panel 的现有 API 合同保持不变。
- 主要变化集中在凭证列表 UI；升级后表格和卡片的信息密度、列宽与额度窗口数量可能与 v1.12.11 不同。
