# CPA Manager Plus v1.12.1

> 7 commits · 103 files changed · +2616 / -613

## Overview

`v1.12.1` brings synchronized CPAMP branding, lossless CPA cooling-policy overrides, and more compatible plugin-host styling to the stable branch. This release changes frontend behavior and documentation only; it does not change Manager Server APIs, database schemas, or stored credential formats.

## Highlights

### Features

- 统一的 CPAMP 品牌资源覆盖 favicon、加载页、登录页、展开和收缩边栏以及 README，并提供明暗主题 SVG 与高密度 PNG。
- Provider 与凭证配置提供“继承全局、启用冷却、禁用冷却”三态策略，用户可以明确表达局部冷却覆盖。

### Fixes

- 冷却策略在 provider 与 auth-file 的读取、编辑、序列化和回滚过程中保留显式 true、false、null 与缺失值，并按 CPA 能力保护旧版和未验证构建。
- 插件宿主样式使用低优先级的隔离基线并让位于插件自有样式，插件颜色、控件、字体和背景可以正常生效。
- 登录和加载页面移除重复标题、副标题，并在固定尺寸下使用合适密度的资源保持 logo 清晰。

## Upgrade Notes

- 本版本不包含数据库迁移、API 合约变化或凭证存储格式变化。
- 冷却策略中的“继承全局”会清除局部覆盖；旧版或未验证 CPA 构建无法安全表达新语义时，面板会保持保护行为。
- 品牌资源在前端构建时内置，不需要额外配置；明暗主题会自动选择对应资源。
