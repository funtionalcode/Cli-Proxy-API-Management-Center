## Overview

v1.14.9 is a 1.x security-maintenance release after v1.14.8. It contains the merged dependency and CI-security maintenance changes in #1049. The focus is to use patched build toolchains and dependencies and prevent future changes with failing dependency scans from passing the existing CI gate.

**There are no new user-facing features.** This release does not include v2 architecture work or change CPA management APIs, authentication, database schemas, credential/configuration formats, or historical usage data.

## Security and Build Maintenance

- **Go and Manager Server (#1049):** Require Go **1.26.10** for source builds, update `golang.org/x/sys` to **v0.44.0**, select the CI Go version from `go.mod`, and pin the Docker Go builder. The SQLite dependency remains at **v1.46.1**.
- **Node.js and frontend dependencies (#1049):** Pin Docker's frontend builder to Node.js **22.23.4** and CI to **24.22.1**. Update axios, React Router, Vite, Vitest, and related locked dependencies.
- **Documentation dependencies (#1049):** Resolve relevant VitePress/DocSearch advisories with scoped dependency overrides while retaining VitePress 1.6.4, without undertaking a documentation-site redesign.
- **Ongoing dependency security (#1049):** Add a full-workspace npm audit and Go vulnerability scans for Linux, macOS, and Windows on both amd64 and arm64. Missing, skipped, or failed results now block Required checks. Add scheduled security scans and weekly Dependabot updates targeting `dev`.
- The verification recorded on #1049 reduced the npm audit from 26 affected package nodes to **zero reported advisories** and found no known issues in the six Go source scan targets. These are findings against the vulnerability database snapshot used for that verification, not a guarantee against future advisories.

## Upgrade Notes

- **Upgrade from v1.14.8 and restart normally.** No database migration, configuration rewrite, or credential recreation is required; `migration_required` remains `false`.
- Users of prebuilt Docker images or native packages do not need to install Go or Node.js on the host. **Source builds** of Manager Server now require Go **1.26.10**; Node.js builds require compatible **22.23.4+ (22.x)**, **24.22.1+ (24.x)**, or **26.12.1+** runtimes.
- The dependency/toolchain changes are substantial, but no user-visible UI, authentication, API, or data behavior changes are intended. Check the management UI, existing connections, and key workflows after upgrading.
- The CPA compatibility baseline for full Muse / Meta features remains **v7.3.4+**.
- The existing offline derived-index maintenance guidance from v1.14.7 still applies; this release adds no further maintenance steps.
- #1049's local verification covered frontend/server tests, offline pages, and native cross-builds. Local Docker build completion was blocked by a base-image metadata fetch error. Formal CI and the release Dry Run remain the authority for publish readiness.
