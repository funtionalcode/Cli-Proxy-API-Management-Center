## Overview

v1.12.12 focuses on responsive account-list presentation and quota readability. Table and card modes now surface quota windows, historical usage, subscription details, and account metadata more completely, while xAI quota presentation now fails closed for unconfirmed plans. This release updates frontend presentation and selection logic only; it does not introduce database schema, credential-storage, or raw usage-data migrations.

## Highlights

### Features

- Refresh the responsive Accounts experience across mobile, laptop, and desktop widths, improving provider, plan, subscription, reset-credit, priority, note, and quota presentation while preserving existing account operations. (Web)
- Table mode can display up to four quota windows with adaptive layouts: one window uses the available quota width, three windows use a dedicated third row, and four windows use a 2×2 arrangement while preserving readable space for availability and recent requests. (Web)
- Restore the four historical-usage metrics in both cards and table rows with compact display values and complete accessible values, reducing information loss and narrow-layout overflow. (Web)
- Antigravity `Pro`, `Ultra`, and `Ultra Lite` cards can now show all four `5h` / `7d` quota windows directly, grouped by model family; other providers and Antigravity Free retain a more compact window count. (Web)
- Improve priority and note presentation in the account list while retaining inline editing behavior. (Web)

### Fixes

- xAI Free and unrecognized plans no longer expose billing limits as quota. Only explicitly recognized paid plans surface quota / PAYG presentation, while raw billing responses remain available for diagnostics. (Web)
- Align main-list quota-window selection, ordering, and historical-usage targets so rendered windows and usage queries remain consistent. (Web)

## Upgrade Notes

- No database schema migration is required, and usage history or credential storage is not modified.
- No new required configuration is introduced; existing Manager Server and CPA-hosted / external-panel API contracts remain unchanged.
- Most changes are concentrated in the Accounts UI, so table/card information density, column widths, and visible quota-window counts may differ from v1.12.11 after upgrading.
