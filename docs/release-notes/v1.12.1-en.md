## Overview

`v1.12.1` brings synchronized CPAMP branding, lossless CPA cooling-policy overrides, and more compatible plugin-host styling to the stable branch. This release changes frontend behavior and documentation only; it does not change Manager Server APIs, database schemas, or stored credential formats.

## Highlights

### Features

- Use one CPAMP brand asset set across the favicon, splash screen, login page, expanded and collapsed sidebars, and README, with theme-aware SVGs and density-aware PNGs.
- Expose Inherit global, Enable cooling, and Disable cooling as explicit provider and credential policies.

### Fixes

- Preserve explicit true, false, null, and missing cooling values across provider and auth-file reads, editing, serialization, and rollback, while guarding legacy and unverified CPA builds by capability.
- Scope the plugin-host baseline at low priority so plugin-owned colors, controls, typography, and surfaces can take precedence.
- Remove duplicate title and subtitle copy from the login and splash screens, and use suitable-density assets for crisp fixed-size logo rendering.

## Upgrade Notes

- This release includes no database migration, API contract change, or credential storage-format change.
- Selecting Inherit global clears the local override; older or unverified CPA builds keep fail-closed compatibility protection when they cannot safely express the new semantics.
- Brand assets are bundled at frontend build time and require no extra configuration; the matching light or dark resource is selected automatically.
